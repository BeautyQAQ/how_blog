# 项目推进记录（2026-11-05）

## 本轮范围

已建立文章内容发布链路、升级两个前端，并继续完成 Markdown、图片上传和文章摘要。阿里云短信配置、服务启动、发送和注册验证码均暂缓。

### 已实现

- 后续权限收口：网关与三个服务共用按方法/完整路径匹配的白名单，其余历史管理和内部搜索接口默认要求管理员；匿名/无效令牌401、角色不符403。Feign 转发调用者身份。
- 账号响应不再输出密码；管理员/普通用户创建和改密统一 BCrypt，省略密码保留原值；首位管理员改为显式的本机启动初始化，禁用管理员不能登录。JWT 强制过期，新签发最多一小时。
- 公开评论只返回公开文章下的已审核内容；提交要求普通用户身份，作者与审核字段由服务端控制。删除文章同时清理关联评论。权限细则、初始化和剩余限制见 [账号与接口权限](security.md)。

- 管理端迁移到 Vue 3 / Vite 8 / Element Plus / Pinia / Vue Router 5 / Axios 1 / ESLint 10；文章、频道、专栏、评论、标签和城市管理迁移为新界面。
- 前台迁移到 Nuxt 4 / Vue 3 / TypeScript 6，使用 Nitro 同源代理、useFetch 与 SSR；首页改为真实文章列表，新增详情、分页、频道和关键词查询、空状态、错误与重试。
- 新文章默认 Markdown，可切换纯文本；编辑器支持工具栏、编辑/对照/预览、正文图片插入。预览与公开详情共用后端渲染和清洗，支持标题、列表、引用、代码块、表格与删除线。
- 管理员可上传经过真实解码和重编码的 PNG/JPEG，用于封面或正文；5MB/像素限制、随机文件名、公开读取、引用保护删除和本地持久目录已实现。
- 摘要支持手填（最多300字），留空由服务端生成180字正文摘要。公开列表使用不读取/返回完整正文的 DTO，前台卡片展示摘要/封面，详情与 SEO 元数据使用同一摘要。
- 新文章由服务端生成 ID、创建/更新时间、待审核状态和零计数。新增请求不能直接伪造审核通过；标题、正文与分页参数有后端校验。
- 新增公开查询接口：GET `/article/public?page=1&size=10&channelid=&keyword=` 与 GET `/article/public/{id}`。经网关时前面再加 `/article`。两者均限制 state=1、ispublic=1；详情不满足条件返回 HTTP 404。
- 原始文章列表、详情、搜索和写接口要求管理员 JWT；普通用户为 403，无效/缺失 JWT 为 401。此规则在文章服务中执行，直连该服务也生效。
- 审核读取数据库的最新状态并同步 ES；公开文章编辑使用索引 upsert，隐藏/删除移除索引。索引失败不再报告审核成功，MySQL 事务回滚。草稿新增、编辑、删除不依赖 ES。
- 编辑保留服务端创建时间、作者和计数；分类 ID 精确匹配；点赞可处理历史 null，写操作在事务提交后清理 Redis；全量索引初始化仅提取公开已审核文章。
- 前端账号退出不再调用不存在的 logout 接口；401 清理会话；修复原审核按钮的未定义变量与索引初始化按钮的错误方法。
- 两个前端提供 package-lock.json、Node 24 约束及独立 README。历史源码保存在各自 legacy 目录，不参与现行构建。

### 实现边界

- 旧文章保留 text 格式，新增字段由一次性迁移添加并回填摘要；不把历史正文自动解释为 Markdown。原始 HTML 按文字显示，危险链接/图片协议被清洗。
- 图片目前使用文章服务的本地持久目录；生产部署需挂载并备份，多个实例需共享目录或后续接对象存储。图片 URL 为独立公开资源，隐藏文章不会撤回图片和浏览器缓存；孤立上传暂未自动清理。详见 [使用与部署说明](article-content.md)。
- 前台关键词检索走 MySQL 的公开过滤查询；ES 用于现有管理搜索接口，文章变更仍同步 ES。后续增加专门的公开 ES 查询。
- ES 与 MySQL 不具备跨系统原子事务。当前可处理调用失败并回滚 MySQL；ES 已成功、随后 MySQL 提交失败等极端情况仍需要事务 outbox、幂等重试和对账补偿。Redis 清理故障也需要后续补偿。
- 历史管理和搜索内部接口已统一鉴权；历史问答、吐槽和交友暂按管理员入口保护，尚未开放普通用户使用。业务服务和中间件仍应保持内网；登录限流与单令牌撤销另行实现。
